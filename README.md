# Student Grade Calculator Using Java

## About the Project

Student Grade Calculator is a Java-based application that calculates a student's total marks, percentage, grade, and final result.

The application allows the user to enter the student's name, roll number, number of subjects, subject names, maximum marks, and obtained marks. It then calculates the result automatically.

## Features

- Enter student name and roll number
- Select the number of subjects
- Enter different maximum marks for each subject
- Enter obtained marks for each subject
- Calculate total marks
- Calculate percentage
- Calculate grade
- Display PASS or FAIL result
- User-friendly Java Swing graphical interface
- Clear and Exit options

## Grading System

| Percentage | Grade |
|------------|-------|
| 90% and above | A+ |
| 80% – 89% | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| 40% – 49% | E |
| Below 40% | F |

A student passes only if they score at least 40% in every subject.
